> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让图谱路从「结构性地不可能命中中文」变成「有层级、有正文实体、能匹配用户说出的标题」，并把评估集扩大到足以判定判据 1 的规模。

**Architecture:** 三处独立修复——（A）把 `heading_path` 层级落成 `belongs_to` 边，让 `neighbors()` 第一次真有东西可扩；（B）从正文抽 `identifier` 节点 + `mentioned_in` 边；（C）修 `_contains_phrase` 在无空格语言上的 bug。三处都只在既有模块内改动，不引入新依赖。

**Tech Stack:** Python 3 · SQLite · NetworkX · pytest

**Spec:** [`docs/superpowers/specs/2026-10-09-rag-v2-m2.5-graph-fix-design.md`](../specs/2026-10-09-rag-v2-m2.5-graph-fix-design.md)

## Global Constraints

- **零回归**：`py -m pytest -q` 必须全绿。本计划开始时基线为 **279 passed, 3 deselected**。
- **图谱抽取是纯规则、零 LLM**：不得引入任何模型调用、网络、随机性。这是本项目图谱路的既有契约。
- **可复现**：同一输入两次运行，实体、关系、排序逐字节一致。
- **确定性排序**：`extract()` 的输出排序规则不变。
- **不引入新依赖**：不加图数据库、不加分词库以外的东西（`jieba` 已在用）。
- **凭据不硬编码**：不得读取、打印或回显任何 API key 或 `.env` 内容。
- **降级不静默**：解析失败落降级码/异常，不吞掉、不伪造。
- **ASCII 别名的词边界行为必须逐字节不变**——它是防 `url` 匹配 `curling` 的机制，改动 C 只允许对**含 CJK 的别名**走新路径。

## Review Focus

以下五类是 spec 隐含、但若不专门写测试就不会被覆盖的失败模式。每一条都在对应任务里落成测试。

1. **中文标题的编号前缀** —— `(1)如何检查…` / `2.3 配置环境变量` 这类前缀若参与匹配，标题就永远匹配不上。（Task 22）
2. **ASCII 词边界的回归** —— 改动 C 若顺手把英文路径也改了，`url` 会重新匹配 `curling`，静默降低精度。（Task 22）
3. **`identifier` 混进父标题链** —— 若 `identifier` 进了 `_STRUCTURAL_KINDS`，后续标题会用标识符做命名限定，污染整条层级。（Task 21）
4. **大小写双向匹配** —— 只登记原样别名时，全小写的查询命不中全大写的节点（`_normalize` 会 `.lower()`）。（Task 21）
5. **短标题在全库泛匹配** —— 没有 `MIN_CJK_RUN` 下限时，「介绍」「说明」这类标题会在几乎每个查询上命中，把图路变成噪声源。（Task 22）

def _ids(ents):

def test_extracts_full_upper_snake_constant():

    assert {"docker-compose.yml", "config.json"} <= _ids(ents)

def test_extracts_path_with_extension():

    assert "projects/code-sandbox/src/env.ts" in _ids(ents)

def test_does_not_extract_chinese_full_stop():
    ents, _ = extract([_chunk("c", ["概述"], "这是一句话。这是另一句。")])
    assert _ids(ents) == set()

def test_extracts_backticked_term():
    ents, _ = extract([_chunk("c", ["接口"], "传 `appId` 即可")])
    assert "appId" in _ids(ents)

def test_unpaired_backtick_is_not_extracted_and_does_not_raise():
    ents, _ = extract([_chunk("c", ["接口"], "落单的 ` 反引号")])
    assert _ids(ents) == set()

def test_identifier_is_never_an_edge_endpoint():
    """⚠️ Review Focus 3：identifier 不得混进层级，否则污染后续命名。"""

    for r in rels:
        if r.kind == "belongs_to":
            assert r.src not in ids and r.dst not in ids

def test_both_cases_match_the_same_node():
    """⚠️ Review Focus 4：_normalize 会 lower()，两种写法都要能命中。"""
    ents, _ = extract([_chunk("c", ["配置"], "设 MULTIPLE_DATA_TO_BASE64 为 false")])
    ent = next(e for e in ents if e.canonical == "MULTIPLE_DATA_TO_BASE64")
    assert "multiple_data_to_base64" in ent.aliases

def test_identifier_enters_posting_list():
    chunk = _chunk("c", ["配置"], "设 MULTIPLE_DATA_TO_BASE64 为 false")
    assert "MULTIPLE_DATA_TO_BASE64" in entities_of_chunk(chunk)

def test_mentioned_in_points_at_heading_leaf():
    _, rels = extract([_chunk("c", ["配置", "环境变量"], "设 MULTIPLE_DATA_TO_BASE64")])
    assert any(
        r.kind == "mentioned_in" and r.src == "MULTIPLE_DATA_TO_BASE64" and r.dst == "环境变量"

    )

def test_chunk_without_heading_still_contributes_identifiers():
